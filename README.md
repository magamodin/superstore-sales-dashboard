# 📈 Superstore | Sales Performance Dashboard

Microsoft Excel vasitəsilə hazırlanmış, pərakəndə satış məlumatlarının hərtərəfli təhlilini və maliyyə göstəricilərini əks etdirən interaktiv satış paneli.

---

## 🚀 Layihə Haqqında
Bu dashboard pərakəndə satış şəbəkəsinin aylıq və illik performansını, regional satış həcmlərini, ştatlar üzrə mənfəətliliyi izləmək və biznes qərarlarına dəstək olmaq üçün yaradılmışdır.

* **Əsas Göstəricilər (KPIs):**
  * **Ümumi Satış (Total Sales):** $540,075.29 *(Ötən ilə nisbətən -3.42%)*
  * **Ümumi Mənfəət (Total Profit):** $58,451.61 *(Ötən ilə nisbətən +19.83%)*
  * **Ümumi Mənfəət Marjası (Profit Margin):** 10.82% *(Ötən ilə nisbətən +2.10%)*

---

## 📊 Dashboard Xüsusiyyətləri və Vizuallar

1. **İllik Filtrlər (Slicer):** 2014, 2015, 2016 və 2017 illəri arasında sürətli keçid.
2. **Total Sale vs Profit vs Profit Margin:** Aylıq satış, mənfəət və marja göstəricilərinin xətt və sütunlu qrafiki.
3. **Total Sales by Region:** Regionlar üzrə ümumi satış həcmi (East, West, Central, South).
4. **Top 10 Sales & Profit by State:** Ştatlar üzrə ən çox satış və mənfəət gətirən bölgələr.
5. **Top 5 Profit Margin & Loss by State (%):** Ən yüksək marja əldə edən və ən çox zərər edən ştatların pay bölgüsü.
6. **Detal Cədvəli:** Aylıq əsasda satış, mənfəət və faiz göstəricilərini əks etdirən strukturlaşdırılmış cədvəl.

---

## 🛠️ İstifadə Olunan Alətlər
* **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicer filtrləri, Qabaqcıl qrafik dizaynı və Məlumat analitikası.
